# 🪵 Ghanshyam Sharma Carpenter (30+ Years Experience)

A modern, responsive, mobile-first website for **Ghanshyam Sharma Carpenter** with 30+ years of craftsmanship experience. Built with **Next.js 14 (App Router)** and **Tailwind CSS**, ready to deploy to **Vercel** via **GitHub**.

## 🌟 Highlights
- 📱 **Mobile-First Experience**: Sticky bottom quick bar for phone users (Call Now, WhatsApp Direct, Work Feed, Cost Estimator).
- 📸 **Daily Photos & Video Posting Portal**: Dedicated Admin Panel (`/admin`) protected by a 4-digit PIN (`1234`) to post work updates directly from a smartphone camera or gallery.
- 📐 **Interactive Cost Estimator**: Instant budget calculator for kitchens, wardrobes, temples, beds, and full homes.
- 🔄 **Before & After Slider**: Interactive restoration slider comparing old worn furniture to Italian PU luxury finish.
- 🌐 **Bilingual Support**: One-tap toggle between Hindi and English.
- ⚡ **Zero-config Vercel Deployment**: Optimized for Vercel's edge network.

## 🚀 Quick Start
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
